# tommbk50-hub.github.io

My personal site, published with GitHub Pages + Jekyll.

**Live at:** https://tommbk50-hub.github.io

## Editing

- Pages are Markdown files in the repo root (`index.md`, `about.md`, `projects.md`).
- Each page starts with YAML front matter (the `---` block) — keep it.
- Site title/description/theme live in `_config.yml`.
- Commit to `main` and the site rebuilds automatically in about a minute.

## Changing the theme

Edit the `theme:` line in `_config.yml`. Supported options include:
`jekyll-theme-minimal`, `jekyll-theme-cayman`, `jekyll-theme-slate`,
`jekyll-theme-architect`, `jekyll-theme-midnight`, `jekyll-theme-hacker`.
